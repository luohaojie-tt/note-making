> 作者：A股短线投资者

---

## 一、核心模式

| 要素 | 规则 |
|-----|------|
| **做什么** | 主线题材中的连板接力 |
| **做几板** | 不拘泥于几板，重点看题材地位和个股地位 |
| **偶尔做** | 首板 |
| **不做** | 退潮期接力、接力加速连板 |

---

## 二、选股条件

### 2.1 题材要求

- ✅ 做主线题材（热度高、资金流入明显、涨停家数多、有持续性）
- ❌ 不做纯消息杂毛（只有消息、没有涨停梯队）
- ❌ 题材很热但核心票竞价不及预期 → 放弃整个题材

### 2.2 个股要求

| 条件 | 要求 |
|-----|------|
| **地位** | 龙头 > 卡位 > 跟风 |
| **市值** | 30亿 < 市值 < 1000亿 |
| **市值例外** | 千亿市值只做首板，不做连板 |
| **龙虎榜** | 不能有"三板组"买入痕迹 |

### 2.3 上板要求

| 条件 | 要求 |
|-----|------|
| **上板时间** | 早盘优先，10点前最好 |
| **拉升方式** | 主动大单拉升、大单扫板 |
| **不喜欢** | 小单推动、一字板、连续加速板 |

### 2.4 认可的特殊形态

- 前一日是烂板、放量板
- 次日早盘快速缩量涨停
- 分歧后的转强

---

## 三、市场环境判断

### 3.1 可做接力

| 条件 | 标准 |
|-----|------|
| 连板高度 | 有个股打开连板高度，市场有5连板及以上 |
| 核心龙头 | 反馈良好 |
| 炸板率 | 可接受 |
| 涨停家数 | 情绪结构支持连板延续 |

### 3.2 谨慎接力

| 条件 | 标准 |
|-----|------|
| 跌停家数 | > 8家 |
| 核心龙头 | 反馈一般或走弱 |
| 炸板率 | 提升 |
| 亏钱效应 | 开始扩散 |

### 3.3 退潮不做

| 条件 | 标准 |
|-----|------|
| 跌停家数 | > 10家 |
| 亏钱效应 | 快速扩散 |
| 核心龙头 | 明显走弱 |
| 连板高度 | 压制明显 |
| 市场 | 无持续性 |

### 3.4 判断权重

每次分析必须同时评估：
1. 连板高度
2. 涨停家数
3. 跌停家数
4. 炸板率
5. 核心龙头反馈 ← **权重最高**

---

## 四、板块热度判断

### 4.1 主线题材标准

- 热度高
- 有明显资金流入
- 题材内部涨停家数足够多
- 市场讨论热度高
- 具备持续性和板块效应

### 4.2 支线题材

- 轮动题材
- 主线分歧时承接资金的方向
- 持续性弱于主线

### 4.3 一日游题材

- 昨天很强，今天明显走弱
- 没有持续性
- 缺乏梯队延续

### 4.4 量化判断方法

| 方法 | 标准 |
|-----|------|
| 板块涨停家数 | ≥ 3只 = 热门 |
| 板块涨幅排名 | 前10名 |
| 板块资金净流入 | 主力净流入越多越好 |

---

## 五、买入条件

### 5.1 优先买入

- 主线题材中的连板接力
- 有带动性的龙头板
- 早盘快速拉升上板
- 弱转强板
- 分歧转一致板
- 炸板回封板

### 5.2 弱转强特征

- 前一日走势不强
- 次日竞价明显强势
- 开盘后主动拉升
- 快速秒板

### 5.3 分歧转一致特征

- 题材先分歧
- 龙头同步分歧
- 盘中重新转强
- 并带动板块回流

### 5.4 不做的情况

- ❌ 一字板
- ❌ 连续加速板
- ❌ 退潮期接力板
- ❌ 纯跟风板
- ❌ 容易封不住的杂毛板
- ❌ 市值 < 30亿
- ❌ 龙虎榜有"三板组"买入
- ❌ 千亿市值连板（非首板）

### 5.5 买入条件的量化方案

> 部分条件难以精确量化，先用近似方案，后续实盘测试调整

| 人工判断 | 量化近似方案 | 量化表达式 |
|---------|-------------|-----------|
| **主线题材连板** | 板块涨停家数 >= 3 | `sector_limit_count >= 3` |
| **有带动性** | 板块内涨停数量越多，带动性越强 | `sector_momentum = count_limit_up_in_sector` |
| **早盘快速上板** | 上板时间 < 10:00 | `limit_up_time < "10:00"` |
| **弱转强** | 昨日涨幅 < 5%，今日高开 > 3% | `yesterday_return < 5 and today_open_return > 3` |
| **分歧转一致** | 曾炸板（最高=涨停价），收盘封住 | `high == limit_price and close == limit_price` |
| **炸板回封** | 盘中曾涨停打开，最终收盘仍涨停 | `was_broken == True and finally_sealed == True` |

#### 量化实现说明

```python
# 1. 主线题材连板
hot_sector = sector_limit_count >= 3  # 热门板块
is_lianban = yesterday_limit_up and today_limit_up  # 连板

# 2. 早盘上板
morning_board = limit_up_time < "10:00"

# 3. 弱转强
weak_to_strong = (yesterday_return < 5) and (today_open_return > 3)

# 4. 分歧转一致 / 炸板回封
was_broken = high == limit_price  # 曾炸板
finally_sealed = close == limit_price  # 最终封住
division_to_unison = was_broken and finally_sealed

# 5. 一字板（不做）
yiziban = open == limit_price and close == limit_price

# 6. 连续加速板（不做）
# 连续3天涨幅>7% = 加速
```

#### 完整量化选股函数

```python
def should_buy(stock):
    """
    买入条件（量化版）
    """

    # ===== 基础条件 =====
    cond1 = stock.limit_streak >= 2        # 连板（2板及以上）
    cond2 = stock.market_cap > 30e8         # 市值>30亿
    cond3 = stock.market_cap < 1000e8       # 市值<1000亿
    cond4 = stock.turnover_rate > 30        # 换手率>30%
    cond5 = stock.is_yiziban == False       # 不是一字板

    # ===== 市场环境 =====
    cond6 = stock.market_limit_down < 10   # 非退潮期（跌停<10）

    # ===== 上板特征 =====
    cond7 = stock.limit_up_time < "10:00"  # 早盘上板
    cond8 = stock.sector in hot_sectors     # 热门板块

    # ===== 综合 =====
    return cond1 and cond2 and cond3 and cond4 and cond5 and cond6 and cond7 and cond8
```

#### 量化的局限性

| 条件 | 量化难度 | 说明 |
|-----|---------|------|
| 带动性 | ⭐⭐⭐⭐⭐ | 几乎无法精确量化，用板块涨停数近似 |
| 弱转强 | ⭐⭐⭐ | 可以用高开幅度近似 |
| 分歧转一致 | ⭐⭐ | 炸板回封可量化 |
| 盘口主动性 | ⭐⭐⭐⭐⭐ | 需要逐笔成交数据 |

## 六、卖出规则

### 6.1 次日预期与操作

| 情况 | 次日预期 | 操作 |
|-----|---------|------|
| **1. 10点前涨停，且后续没有炸板** | 高开>3% | 符合预期可格局，不符合卖出；没有主动拉升也卖出 |
| **2. 10点前涨停，但后续炸板>2次** | 0-3% | 符合预期可多看，主动冲击连板则留，否则冲高走 |
| **3. 10点后涨停，且后续没有炸板** | 0-3% | 主动冲击连板则留，否则冲高走 |
| **4. 10点后涨停，炸板>2次，但14:30后未再开板** | 0-3% | 主动冲击连板则留，否则冲高走 |
| **5. 10点后涨停，炸板>2次，且14:30后仍炸板** | -3-0% | 一般冲高卖出，除非继续连板 |
| **6. 打板没封住** | -3-0% | 一般冲高就走，除非出现弱转强或反包板 |

### 6.2 止损规则

| 条件 | 止损线 |
|-----|-------|
| **一般止损** | -3%（亏损3%） |
| 冲板炸板后 | 涨幅从高点跌破 +7%（从10%跌到7%时卖） |
| 单票最大回撤 | -10% |
| 单日最大回撤 | -5% |

### 6.3 持股原则

- 不连板就走人
- 只有继续主动冲击涨停才愿意格局
- 不主动的票，不应硬拿

## 七、仓位管理

| 规则 | 数值 |
|-----|------|
| 同时持股 | 2只 |
| 单次出手 | 约5成仓 |
| 强势龙头第一天买得不够 | 第二天上板还会继续买 |
| 连续亏钱后 | 压缩到1成或空仓 |

### 空仓条件

- 大盘行情差
- 市场情绪差
- 没有明确主线题材
- 明显退潮期

---

## 八、盘口与分时

### 8.1 喜欢的盘口

- 有大单主动拉升
- 有大单主动扫板
- 资金态度坚决

### 8.2 不够理想的盘口

- 没有明显主动大单
- 主要依靠小单推动

---

## 九、必须避免的错误交易

1. 板块活口误判成真正机会
2. 连续亏损后因急于回本而冲动交易
3. 连续加速连板的高位接力
4. 题材加速后的假弱转强
5. 退潮期硬做接力
6. 当日容易封不住的板

## 十一、候选股输出格式（参考）

每只候选股输出：

- 股票名称
- 所属题材
- 龙头/前排/卡位/跟风属性
- 打板时机
- 是第一次上板参与，还是炸板回封参与
- 入选理由
- 竞价是否符合预期
- 主要风险点
- 是否容易封不住
- 放弃条件
