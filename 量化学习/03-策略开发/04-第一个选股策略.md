## 4.1 什么是选股策略？

**选股策略 = 一套规则，帮你从4000只股票里选出符合条件的股票**

你做连扳时，潜意识里其实有一套规则：
- 昨天涨停
- 今天高开/平开
- 成交量放大
- 不是ST股票
- 板块有热度

**量化就是把这套规则明确写出来！**

---

## 4.2 连扳模式的量化规则

```python
def is_good_stock(df):
    """
    判断一只股票是否符合连扳接力模式
    返回: True/False
    """

    # 条件1：昨天涨停（至少9.9%）
    yesterday = df.iloc[-2] if len(df) >= 2 else None
    if yesterday is None:
        return False

    is_limit_up = yesterday['pct_change'] >= 9.9

    # 条件2：今天开盘不是一字板（有换手机会）
    today = df.iloc[-1]
    not_zijinban = today['open'] < today['close']  # 不是开盘涨停收盘也涨停

    # 条件3：成交量放大（至少1.5倍）
    volume_amplified = today['volume_ratio'] > 1.5

    # 条件4：股价在20日均线上方（趋势向上）
    above_ma20 = today['close'] > today['ma20']

    # 条件5：不是ST股票（需要另外的数据源，这里先简化）

    return is_limit_up and not_zijinban and volume_amplified and above_ma20
```

## 4.3 全市场选股流程

```python
import akshare as ak
import pandas as pd
from tqdm import tqdm  # 进度条库

def get_all_stocks():
    """获取全市场股票列表"""
    df = ak.stock_zh_a_stock_symbols()
    return df

def check_stock_today(stock_code):
    """检查某只股票今天是否符合条件"""

    try:
        # 获取最近20天数据
        df = ak.stock_zh_a_hist(
            symbol=stock_code,
            period='daily',
            start_date='20240201',
            end_date='20240313'
        )

        # 数据处理
        df = df.sort_values('日期')
        df = df[['日期', '开盘', '收盘', '最高', '最低', '成交量', '涨跌幅']]
        df.columns = ['date', 'open', 'close', 'high', 'low', 'volume', 'pct_change']
        df['date'] = pd.to_datetime(df['date'])
        df = df.set_index('date')

        # 计算指标
        df['ma20'] = df['close'].rolling(window=20).mean()
        df['vol_ma5'] = df['volume'].rolling(window=5).mean()
        df['volume_ratio'] = df['volume'] / df['vol_ma5']

        if len(df) < 2:
            return False

        yesterday = df.iloc[-2]
        today = df.iloc[-1]

        # 连扳条件
        is_limit_up = yesterday['pct_change'] >= 9.9
        not_zijinban = today['open'] < today['close']
        volume_amplified = today['volume_ratio'] > 1.5
        above_ma20 = today['close'] > today['ma20']

        return is_limit_up and not_zijinban and volume_amplified and above_ma20

    except Exception as e:
        return False

# 扫描全市场选股
print("开始扫描全市场...")
stocks = get_all_stocks()

selected = []
for code in tqdm(stocks['代码'].head(100)):  # 先测试100只
    if check_stock_today(code):
        selected.append(code)
        print(f"✓ 选出: {code}")

print(f"\n最终选出 {len(selected)} 只股票")
```

## 本课重点

1. **选股策略 = 明确规则** - 把主观判断写成代码
2. **核心条件**：昨天涨停 + 今天有换手 + 成交量放大 + 趋势向上
