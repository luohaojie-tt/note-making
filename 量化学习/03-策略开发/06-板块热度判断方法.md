> 更新日期：2026-03-13

## 一、为什么需要判断板块热度？

连扳策略的核心是**做热门板块的龙头股**。

- 板块越热，跟风资金越多，涨停后溢价越高
- 冷门板块的涨停股，第二天往往没人接

---

## 二、板块热度判断方法

### 方法1：板块涨幅排名

```python
# 涨幅排名靠前 = 热门

import akshare as ak

# 获取板块涨跌行情
df = ak.stock_sector_spot_summary()

# 按涨幅排序，取前10名
hot_sectors = df.nlargest(10, '涨跌幅')['名称'].tolist()
```

### 方法2：板块涨停家数（最有效）

```python
# 一个板块有10只涨停 = 非常热门
# 只有1只涨停 = 不够热

# 获取当日涨停股票池
df_limit = ak.stock_zt_pool(date='20240313')

# 统计每个板块涨停数量
sector_counts = df_limit['所属行业'].value_counts()

# 取涨停家数 >= 3 的板块
hot_sectors = sector_counts[sector_counts >= 3].index.tolist()
```

### 方法3：板块资金净流入

```python
# 主力资金净流入越多 = 越热门

# 获取板块资金流向
df_money = ak.stock_sector_fund_flow_rank(symbol="今日")

# 按净流入排序
hot_sectors = df_money.nlargest(10, '今日涨跌幅')['名称'].tolist()
```

### 方法4：综合评分（推荐）

```python
import akshare as ak
import pandas as pd

def get_hot_sectors_comprehensive(date=None):
    """
    综合评分判断热门板块
    评分因素：涨幅 + 涨停数 + 资金流入
    """

    if date is None:
        from datetime import datetime
        date = datetime.now().strftime('%Y%m%d')

    # 1. 获取板块涨跌
    df_price = ak.stock_sector_spot_summary(date=date)

    # 2. 获取涨停股票
    try:
        df_limit = ak.stock_zt_pool(date=date)
        limit_counts = df_limit['所属行业'].value_counts()
    except:
        limit_counts = pd.Series()

    # 3. 构建评分表
    score = pd.DataFrame()
    score['sector'] = df_price['名称']
    score['change_pct'] = df_price['涨跌幅']

    # 涨停数（可能没有，填充0）
    score['limit_count'] = score['sector'].map(limit_counts).fillna(0)

    # 4. 标准化评分
    score['price_score'] = (score['change_pct'] - score['change_pct'].min()) / \
                           (score['change_pct'].max() - score['change_pct'].min())

    score['limit_score'] = score['limit_count'] / score['limit_count'].max() if score['limit_count'].max() > 0 else 0

    # 5. 综合得分（涨幅40% + 涨停数60%）
    score['total_score'] = score['price_score'] * 0.4 + score['limit_score'] * 0.6

    # 6. 取前10名
    hot_sectors = score.nlargest(10, 'total_score')['sector'].tolist()

    return hot_sectors
```

## 三、板块数据获取方式

| 数据源 | 方法 | 说明 |
|-------|------|------|
| **akshare** | stock_sector_spot_summary | 板块涨跌 |
| **akshare** | stock_sector_fund_flow_rank | 资金流向 |
| **akshare** | stock_zt_pool | 涨停股票池 |
| **Tushare** | stock_industry | 股票所属板块 |
| **自己计算** | 按股票汇总板块 | 更灵活 |

## 四、在选股策略中使用板块过滤

### 完整示例：连扳策略 + 板块过滤

```python
import akshare as ak
import pandas as pd

def get_hot_sectors_for_lianban(date):
    """
    获取连扳策略关注的热门板块
    """

    # 获取涨停股票
    df_limit = ak.stock_zt_pool(date=date)

    # 统计板块涨停数量
    sector_counts = df_limit['所属行业'].value_counts()

    # 涨停>=3的板块
    hot = sector_counts[sector_counts >= 3].index.tolist()

    return hot


def filter_by_sector(stocks, hot_sectors):
    """
    过滤：只保留热门板块的股票
    """
    # 获取每只股票的所属板块
    df_industry = ak.stock_zh_a_stock_symbols()

    # 过滤
    filtered = []
    for code in stocks:
        try:
            sector = df_industry[df_industry['代码'] == code]['所属行业'].values[0]
            if sector in hot_sectors:
                filtered.append(code)
        except:
            pass

    return filtered


# 使用
hot_sectors = get_hot_sectors_for_lianban('20240313')
print(f"当前热门板块: {hot_sectors}")
```

## 五、判断标准总结

| 方法 | 判断标准 | 适用场景 |
|-----|---------|---------|
| 板块涨幅 Top10 | 涨幅排名靠前 | 快速筛选 |
| 涨停家数 >= 3 | 板块内涨停多 | 连扳策略 |
| 资金净流入 | 主力资金流入 | 趋势策略 |
| 综合评分 | 多因素加权 | 全面判断 |

---

## 六、注意事项

1. **盘中判断困难**：涨停数据收盘后才完整
2. **实时性**：可以用开盘涨幅+竞价情绪近似判断
3. **轮动快**：热点板块切换频繁，需要每日更新

---

## 本课重点

1. **板块热度 = 涨停数量 + 涨幅 + 资金流入**
2. **最有效指标**：板块涨停家数 >= 3
3. **akshare可获取**：stock_zt_pool、stock_sector_spot_summary
4. **结合使用**：涨幅辅助 + 涨停数核心
