## 3.1 为什么需要处理数据？

原始数据往往是"脏"的：
- 有缺失值（如停牌期间没有数据）
- 日期格式不统一
- 需要计算各种指标（均线、MACD等）

---

## 3.2 数据清洗流程

```python
import akshare as ak
import pandas as pd

# 获取数据
df = ak.stock_zh_a_hist(
    symbol='600519',
    period='daily',
    start_date='20240101',
    end_date='20240301'
)

# 标准清洗流程：
# 1. 按日期排序
df = df.sort_values('日期')

# 2. 筛选需要的列
df = df[['日期', '开盘', '收盘', '最高', '最低', '成交量', '涨跌幅']]

# 3. 重命名列（英文更方便后续处理）
df.columns = ['date', 'open', 'close', 'high', 'low', 'volume', 'pct_change']

# 4. 转换日期格式
df['date'] = pd.to_datetime(df['date'])

# 5. 设置日期为索引
df = df.set_index('date')
```

## 3.3 核心技术指标（连扳模式必备）

### 1. 均线系统

| 指标 | 用途 | 周期选择 |
|-----|------|---------|
| MA5 | 短期趋势 | 1周 |
| MA10 | 中期趋势 | 2周 |
| MA20 | 中长期趋势 | 1个月 |

```python
df['ma5'] = df['close'].rolling(window=5).mean()
df['ma10'] = df['close'].rolling(window=10).mean()
df['ma20'] = df['close'].rolling(window=20).mean()
```

### 2. 连板计数（连扳模式核心！）

```python
# 标记涨停日
df['is_limit_up'] = (df['pct_change'] >= 9.9).astype(int)

# 计算连续涨停天数
# 逻辑：遇到非涨停则重置计数
df['limit_streak'] = df['is_limit_up'].groupby(
    (df['is_limit_up'] != df['is_limit_up'].shift()).cumsum()
).cumsum() * df['is_limit_up']
```

### 3. 成交量指标

```python
# 成交量均线
df['vol_ma5'] = df['volume'].rolling(window=5).mean()

# 量价关系：成交量放大倍数
df['volume_ratio'] = df['volume'] / df['vol_ma5']

# 放量上涨
df['volume_up'] = ((df['volume_ratio'] > 1.5) & (df['pct_change'] > 0)).astype(int)
```

### 4. 股价位置指标

```python
# N日内最高/最低价
df['highest_20'] = df['high'].rolling(window=20).max()
df['lowest_20'] = df['low'].rolling(window=20).min()

# 当前位置在N日波动中的位置（0-100%）
df['price_position'] = (df['close'] - df['lowest_20']) / (df['highest_20'] - df['lowest_20']) * 100
```

## 3.4 完整数据处理函数

```python
import akshare as ak
import pandas as pd

def get_stock_data(stock_code, start_date, end_date):
    """获取并处理股票数据"""

    # 1. 获取原始数据
    df = ak.stock_zh_a_hist(
        symbol=stock_code,
        period='daily',
        start_date=start_date,
        end_date=end_date
    )

    # 2. 数据清洗
    df = df.sort_values('日期')
    df = df[['日期', '开盘', '收盘', '最高', '最低', '成交量', '涨跌幅']]
    df.columns = ['date', 'open', 'close', 'high', 'low', 'volume', 'pct_change']
    df['date'] = pd.to_datetime(df['date'])
    df = df.set_index('date')

    # 3. 计算技术指标
    # 均线
    for window in [5, 10, 20, 60]:
        df[f'ma{window}'] = df['close'].rolling(window=window).mean()

    # 连板计数
    df['is_limit_up'] = (df['pct_change'] >= 9.9).astype(int)
    df['limit_streak'] = df['is_limit_up'].groupby(
        (df['is_limit_up'] != df['is_limit_up'].shift()).cumsum()
    ).cumsum() * df['is_limit_up']

    # 成交量指标
    df['vol_ma5'] = df['volume'].rolling(window=5).mean()
    df['volume_ratio'] = df['volume'] / df['vol_ma5']

    return df
```

## 本课重点

1. **数据清洗流程**：排序 → 筛选 → 重命名 → 日期转换 → 设置索引
2. **核心指标**（不管用什么数据源都要用）：
   - **均线**：判断趋势方向
   - **连板计数**：连扳模式的核心信号
   - **成交量放大**：判断资金活跃度
   - **股价位置**：判断相对高低
