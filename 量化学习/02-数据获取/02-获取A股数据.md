## 2.1 为什么数据是量化的基础？

> **没有数据 = 没有量化**
>
> 你要做策略回测，必须要有历史行情数据。买错可以亏钱，但用错数据会让你亏得不明不白。

量化交易的数据类型：

| 数据类型 | 用途 | 例子 |
|---------|------|------|
| **行情数据** | 计算指标、信号 | 开盘价、收盘价、成交量 |
| **财务数据** | 基本面选股 | 市值、净利润、ROE |
| **资金流向** | 判断主力资金 | 北向资金、龙虎榜 |
| **另类数据** | 情绪指标 | 舆情、研报数量 |

---

## 2.2 个人投资者获取数据的渠道

| 渠道 | 优点 | 缺点 | 推荐度 |
|-----|------|------|-------|
| **Tushare Pro** | 数据全、更新快、有API | 收费（但很便宜） | ⭐⭐⭐⭐⭐ |
| **akshare** | 完全免费 | 日线T+1更新，实时数据有延迟 | ⭐⭐⭐⭐ |
| **证券交易所** | 官方数据 | 格式复杂、难解析 | ⭐⭐ |
| **券商平台** | 直接可用 | 只能获取自己开户的 | ⭐ |

### akshare 数据时效性说明

| 用途 | akshare够用吗 | 备注 |
|-----|--------------|------|
| 历史回测 | ✅ 足够 | 日线数据全覆盖 |
| 策略验证 | ✅ 足够 | 复盘用T+1数据 |
| 实盘交易 | ⚠️ 需注意 | 日线信号可以，实时追涨有延迟 |

**结论**：学习阶段用akshare完全没问题，等以后真刀真枪做实盘了再考虑Tushare Pro。

## 2.3 akshare 快速入门

### 安装

```bash
pip install akshare
```

### 获取单只股票日线数据

```python
import akshare as ak

# 获取茅台日线数据
df = ak.stock_zh_a_hist(
    symbol='600519',      # 股票代码
    period='daily',       # 日线
    start_date='20240101',
    end_date='20240301'
)

print(df.head())
```

### 返回数据格式

| 字段 | 含义 |
|-----|------|
| 日期 | 交易日期 |
| 股票代码 | 600519 |
| 开盘 | 开盘价 |
| 收盘 | 收盘价 |
| 最高 | 最高价 |
| 最低 | 最低价 |
| 成交量 | 成交量（手） |
| 成交额 | 成交额（元） |
| 振幅 | 振幅百分比 |
| 涨跌幅 | 当日涨跌幅 |
| 涨跌额 | 当日涨跌额 |
| 换手率 | 换手率 |

### 实际获取数据示例

```python
import akshare as ak

# 获取茅台2024年1-2月数据
df = ak.stock_zh_a_hist(
    symbol='600519',
    period='daily',
    start_date='20240101',
    end_date='20240301'
)

print(f'共获取 {len(df)} 条记录')
print(df.head())
```

## 2.4 数据存储建议

获取数据后，建议保存到本地：

```python
# 保存为CSV（简单）
df.to_csv('600519_daily.csv', index=False)

# 保存为Parquet（推荐，省空间、读取快）
df.to_parquet('600519_daily.parquet')
```
