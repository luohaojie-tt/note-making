## 9.1 优化的核心思路

> **优化不是过度拟合，而是找到策略在历史数据上的最佳参数**

优化常见误区：
- ❌ 优化参数让历史收益最高 → 过拟合
- ✅ 找到稳定盈利的参数组合 → 有效优化

## 9.2 参数优化

```python
import itertools

def parameter_optimization():
    """参数优化"""

    # 定义参数范围
    param_grid = {
        'limit_pct': [9.5, 9.9, 10.0],
        'vol_ratio': [1.2, 1.5, 2.0],
        'hold_days': [1, 2, 3],
        'stop_loss': [-3, -5, -7]
    }

    # 生成所有组合
    keys = param_grid.keys()
    values = param_grid.values()
    combinations = [dict(zip(keys, v)) for v in itertools.product(*values)]

    print(f"总共 {len(combinations)} 种参数组合")

    results = []

    for params in combinations:
        # 用这组参数运行回测
        result = run_backtest_with_params(params)

        results.append({
            'params': params,
            'win_rate': result['win_rate'],
            'total_profit': result['total_profit'],
            'max_drawdown': result['max_drawdown']
        })

    # 按收益排序
    results.sort(key=lambda x: x['total_profit'], reverse=True)

    # 输出最佳参数
    print("\n最佳参数组合:")
    print(results[0])
```

## 9.4 风控优化

```python
class RiskManager:
    """风控管理器"""

    def __init__(self):
        self.max_position = 3         # 最大持仓数
        self.max_loss_perTrade = -5   # 单笔最大亏损 (%)
        self.max_daily_loss = -10     # 单日最大亏损 (%)
        self.stop_profit = 10         # 止盈线 (%)

    def should_buy(self, positions, signal_strength):
        """是否应该买入"""
        # 仓位已满
        if len(positions) >= self.max_position:
            return False
        # 信号强度不够
        if signal_strength < 0.6:
            return False
        return True

    def should_sell(self, position, current_profit):
        """是否应该卖出"""

        # 止损
        if current_profit <= self.max_loss_perTrade:
            return True, 'stop_loss'

        # 止盈
        if current_profit >= self.stop_profit:
            return True, 'stop_profit'

        # 持有超过N天
        if position['hold_days'] >= 3:
            return True, 'time_stop'

        return False, None
```

## 9.5 样本内外测试（避免过拟合）

```python
def walk_forward_test():
    """
    Walk-forward 测试：避免过拟合
    """

    # 样本内：2021-2022年
    in_sample_result = run_backtest('20210101', '20221231')

    # 样本外：2023年
    out_sample_result = run_backtest('20230101', '20231231')

    print(f"样本内收益: {in_sample_result['total_profit']:.2f}%")
    print(f"样本外收益: {out_sample_result['total_profit']:.2f}%")

    # 如果样本外表现差太多，说明过拟合
    if out_sample_result['total_profit'] < in_sample_result['total_profit'] * 0.5:
        print("警告：可能存在过拟合！")
```

## 9.6 优化检查清单

| 检查项 | 标准 | 重要性 |

| 样本外测试 | 收益不应低于样本内50% | ⭐⭐⭐ |

## 9.7 补充：夏普比率（Sharpe Ratio）

### 通俗解释

> **夏普比率 = 每承担1份风险，能获得多少超额收益**

```
夏普比率 = (收益 - 无风险利率) / 波动率
```

### 判断标准

| 夏普比率 | 评价 |
|---------|------|
| > 2.0 | 优秀 |
| 1.0 - 2.0 | 良好 |
| 0.5 - 1.0 | 一般 |
| < 0.5 | 较差 |

### 对你的意义

连扳策略收益高但波动也大（经常涨停后跌停），所以夏普比率可能不高。量化追求的是**稳定的收益曲线**，而不是突然暴富。
