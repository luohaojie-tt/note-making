## 5.1 什么是回测？

**回测 = 用历史数据模拟交易，验证策略能否赚钱**

> 不用交学费就能知道策略好不好——这就是回测的价值

```
实盘前：
策略 → 回测验证 → 优化 → 实盘

vs 你的现状：
策略 → 直接实盘 → 亏钱 → 换策略 → 亏钱 → ...
```

---

## 5.2 回测的核心指标

| 指标 | 含义 | 好的标准 |
|-----|------|---------|
| **收益率** | 总收益 | 年化 > 20% |
| **胜率** | 盈利次数/总交易次数 | > 40%（短线） |
| **盈亏比** | 平均盈利/平均亏损 | > 1.5 |
| **最大回撤** | 最惨时亏多少 | < 20% |
| **夏普比率** | 风险调整后收益 | > 1 |

## 5.3 简单回测框架

```python
import akshare as ak
import pandas as pd
import numpy as np

def backtest(stock_code, start_date, end_date):
    """
    简单回测：昨天涨停买入，今天卖出
    """

    # 1. 获取数据
    df = ak.stock_zh_a_hist(
        symbol=stock_code,
        period='daily',
        start_date=start_date,
        end_date=end_date
    )

    # 2. 数据处理
    df = df.sort_values('日期')
    df = df[['日期', '开盘', '收盘', '最高', '最低', '成交量', '涨跌幅']]
    df.columns = ['date', 'open', 'close', 'high', 'low', 'volume', 'pct_change']
    df['date'] = pd.to_datetime(df['date'])
    df = df.set_index('date')

    # 3. 模拟交易
    trades = []
    for i in range(1, len(df) - 1):
        yesterday = df.iloc[i - 1]
        today = df.iloc[i]

        # 买入信号：昨天涨停
        if yesterday['pct_change'] >= 9.9:
            # 第二天开盘买入
            buy_price = today['open']
            # 第三天开盘卖出（次日冲高出）
            if i + 1 < len(df):
                tomorrow = df.iloc[i + 1]
                sell_price = tomorrow['open']

                profit_pct = (sell_price - buy_price) / buy_price * 100
                trades.append({
                    'buy_date': yesterday.name,
                    'sell_date': tomorrow.name,
                    'buy_price': buy_price,
                    'sell_price': sell_price,
                    'profit_pct': profit_pct
                })

    # 4. 统计结果
    if not trades:
        return {'total_trades': 0, 'win_rate': 0, 'avg_profit': 0}

    wins = [t for t in trades if t['profit_pct'] > 0]
    total_profit = sum(t['profit_pct'] for t in trades)

    result = {
        'total_trades': len(trades),
        'win_rate': len(wins) / len(trades) * 100,
        'avg_profit': total_profit / len(trades),
        'total_profit': total_profit,
        'trades': trades
    }

    return result

# 测试：回测茅台
result = backtest('600519', '20230101', '20231231')
print(f"交易次数: {result['total_trades']}")
print(f"胜率: {result['win_rate']:.1f}%")
print(f"平均收益: {result['avg_profit']:.2f}%")
print(f"总收益: {result['total_profit']:.2f}%")
```

## 5.4 连扳策略回测示例

```python
def backtest_lianban_strategy(stock_code, start_date, end_date):
    """
    连扳策略回测：
    买入条件：昨天涨停 + 今天有换手 + 成交量放大
    卖出：次日开盘卖出
    """

    # 获取数据
    df = ak.stock_zh_a_hist(
        symbol=stock_code,
        period='daily',
        start_date=start_date,
        end_date=end_date
    )

    # 数据处理
    df = df.sort_values('日期')
    df = df[['日期', '开盘', '收盘', '最高', '最低', '成交量', '涨跌幅']]
    df.columns = ['date', 'open', 'close', 'high', 'low', 'volume', 'pct_change']
    df['date'] = pd.to_datetime(df['date'])
    df = df.set_index('date')

    # 计算指标
    df['ma20'] = df['close'].rolling(window=20).mean()
    df['vol_ma5'] = df['volume'].rolling(window=5).mean()
    df['volume_ratio'] = df['volume'] / df['vol_ma5']

    # 模拟交易
    trades = []
    for i in range(1, len(df) - 1):
        yesterday = df.iloc[i - 1]
        today = df.iloc[i]

        # 买入条件
        cond1 = yesterday['pct_change'] >= 9.9  # 昨天涨停
        cond2 = today['open'] < today['close']   # 有换手（非一字板）
        cond3 = today['volume_ratio'] > 1.5      # 成交量放大

        if cond1 and cond2 and cond3:
            # 第二天开盘买入
            buy_price = today['open']

            # 第三天开盘卖出
            if i + 1 < len(df):
                tomorrow = df.iloc[i + 1]
                sell_price = tomorrow['open']

                profit_pct = (sell_price - buy_price) / buy_price * 100
                trades.append({
                    'stock': stock_code,
                    'buy_date': str(yesterday.name.date()),
                    'buy_price': buy_price,
                    'sell_price': sell_price,
                    'profit_pct': profit_pct
                })

    return trades

# 回测多只股票
test_stocks = ['600519', '000858', '601318', '300750', '002594']
all_trades = []

for stock in test_stocks:
    try:
        trades = backtest_lianban_strategy(stock, '20230101', '20231231')
        all_trades.extend(trades)
    except:
        pass

# 统计结果
if all_trades:
    df_trades = pd.DataFrame(all_trades)
    wins = df_trades[df_trades['profit_pct'] > 0]

    print(f"总交易次数: {len(df_trades)}")
    print(f"胜率: {len(wins)/len(df_trades)*100:.1f}%")
    print(f"平均收益: {df_trades['profit_pct'].mean():.2f}%")
    print(f"总收益: {df_trades['profit_pct'].sum():.2f}%")
```

## 5.5 回测的局限性（重要！）

| 局限 | 说明 | 如何避免 |
|-----|------|---------|
| **未来函数** | 不小心用到未来数据 | 严格只用过去数据 |
| **流动性** | 假设能买到/卖完 | 设置仓位限制 |
| **滑点** | 实际成交价更差 | 扣除0.2%手续费 |
| **市场变化** | 过去有效将来未必 | 用最近1-2年数据 |

---

## 本课重点

1. **回测价值**：用历史数据验证策略，不用交学费
2. **核心指标**：胜率、盈亏比、平均收益、最大回撤
3. **注意局限性**：未来函数、流动性、滑点、市场变化
