## 10.1 新手常见陷阱

### 陷阱1：过度优化（Overfitting）

```python
# ❌ 错误：把参数优化到完美
# 历史收益100%，但实盘可能亏钱

# ✅ 正确：简单稳健的策略
# 历史收益20%，但实盘稳定
```

**应对**：
- 参数少一点
- 样本外测试
- 接受"不够完美"的策略

### 陷阱2：未来函数

```python
# ❌ 错误：用到未来数据
if df['close'][i] > df['close'][i+1]:  # 用了还没发生的收盘价！
    buy()

# ✅ 正确：只用过去和当前数据
if df['close'][i] > df['close'][i-1]:  # 用昨天的收盘价
    buy()
```

### 陷阱3：忽略交易成本

```python
# ❌ 错误：假设交易0成本

# ✅ 正确：扣除手续费和滑点
fee = 0.0003  # 万三佣金
stamp_tax = 0.001  # 千一印花税（卖出）
slippage = 0.002  # 滑点0.2%

total_cost = fee * 2 + stamp_tax + slippage
```

### 陷阱4：幸存者偏差

```python
# ❌ 错误：只回测现在还活着的股票

# ✅ 正确：包含已经退市/破产的股票
# 很多策略回测很好，但实盘买到了退市股
```

## 10.2 真实市场的问题

| 问题 | 说明 | 应对 |
|-----|------|------|
| **涨跌停买不到** | 热门股根本买不进 | 竞价提前挂单 |
| **涨跌停卖不出** | 跌停板割不掉 | 设置风控线提前卖 |
| **流动性风险** | 小盘股买卖困难 | 只做流动性好的 |
| **大盘环境** | 牛/熊市策略不同 | 分环境调整 |

## 10.3 实战建议

### 1. 从模拟盘开始

```python
# 第一阶段：模拟盘（1-3个月）
- 验证策略能跑通
- 观察实盘与回测的差距
- 调整心态

# 第二阶段：小资金实盘（3-6个月）
- 用1-2万块测试
- 记录每笔交易
- 验证策略有效性

# 第三阶段：正式实盘
- 逐步增加资金
- 持续优化策略
```

### 2. 资金管理

```python
# ❌ 错误：一把梭
all_in('600519')

# ✅ 正确：分批建仓
# 第一次买30%
buy('600519', 30)
# 第二次买30%（如果涨了）
buy('600519', 30)
# 第三次买40%（如果还涨）
buy('600519', 40)
```

### 3. 日志记录

```python
def log_trade(trade):
    """记录每笔交易"""
    with open('trade_log.txt', 'a') as f:
        f.write(f"{datetime.now()} | {trade}\n")

# 记录：买入理由、卖出理由、反思
```

## 10.4 你的连扳策略优化方向

针对你之前做的连扳模式：

| 问题 | 优化方向 |
|-----|---------|
| 被量化收割 | 加快信号反应速度 |
| 炸板率高 | 增加过滤条件（换手率、量能） |
| 第二天低开 | 设置早盘冲高卖出 |
| 回撤大 | 严格止损（-3%） |

## 本课重点

1. **避免过度优化**：简单策略更稳健
2. **注意未来函数**：严格只用历史数据
3. **考虑交易成本**：手续费+滑点
4. **从模拟盘开始**：小资金验证后再放大
5. **做好记录**：复盘是进步的关键
