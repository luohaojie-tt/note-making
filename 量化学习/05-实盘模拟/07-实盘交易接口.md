## 7.1 实盘交易的三种方式

| 方式 | 优点 | 缺点 | 适合人群 |

## 7.3 最简方案：QMT量化终端

**QMT（Quantitative Trading Platform）** 是很多券商免费提供的量化交易软件：

```
券商开户 → 申请QMT权限 → 下载安装 → 编写策略 → 实盘交易
```

**优点**：
- 券商提供，免费
- 不用写太多代码，有可视化界面
- 支持Python策略

**缺点**：
- 只能交易你开户的券商
- 策略需要适配QMT的API

## 7.4 Python直连券商API

如果你想自己写代码，可以用券商的API：

```python
# 某券商API示例（伪代码）
from 券商API import TradeApi

# 初始化
api = TradeApi('你的账号', '你的密码')

# 买入
order_id = api.buy('600519', 100, 1700.0)  # 股票代码、数量、价格

# 查询持仓
positions = api.get_positions()

# 撤单
api.cancel_order(order_id)
```

**注意**：现在券商API管理越来越严格，很多需要现场临柜申请。

## 7.6 实盘交易的核心逻辑

```python
def run_live_strategy():
    """
    实盘策略运行逻辑
    """

    while True:
        # 1. 每天收盘后获取选股结果
        stocks = scan_stocks()  # 扫描全市场选股

        # 2. 开盘前检查持仓
        positions = get_positions()

        # 3. 发送买入信号
        for stock in stocks:
            if len(positions) < MAX_POSITIONS:  # 仓位未满
                # 检查是否已持有
                if stock not in positions:
                    # 发送买入委托
                    buy(stock, quantity=100)

        # 4. 检查卖出信号
        for pos in positions:
            # 卖出条件：涨停板被砸 / 跌幅超过止损线 / 持有超过N天
            if should_sell(pos):
                sell(pos)

        # 5. 等待下一个交易日
        wait_until_next_trading_day()

        # 避免过于频繁，间隔执行
        time.sleep(60)
```

## 7.7 注意事项

| 风险点 | 说明 | 应对 |
|-------|------|------|
| **网络断开** | 程序可能漏单 | 断线重连、检查未成交 |
| **成交滑点** | 实际成交价比信号差 | 预留价格空间 |
| **涨跌停买不到** | 热门股根本买不进 | 竞价时间提前委托 |
| **资金被占用** | 持仓卖不掉 | 设置止损线 |

## 本课重点

1. **实盘途径**：券商API > 量化平台 > QMT
2. **推荐路径**：QMT/聚宽模拟盘 → 实盘
3. **核心注意**：网络稳定性、成交滑点、涨跌停买不到
