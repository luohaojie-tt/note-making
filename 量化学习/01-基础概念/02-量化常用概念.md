## 一、量化因子

### 1.1 什么是因子？

**因子 = 影响股票涨跌的某个特征/指标**

就像你会看"昨天涨停"、"成交量放大"来选股，这些就是你的"因子"。

量化就是把这些因子变成明确的数值，然后用数学公式选股。

### 1.2 常见因子分类

#### 1. 价格因子（技术因子）

| 因子名 | 计算方法 | 含义 |
|-------|---------|------|
| **收益率** | 当日涨跌幅 | 短期涨跌 |
| **MA5/MA10/MA20** | N日均价 | 趋势方向 |
| **MACD** | 指数平滑异同移动平均线 | 趋势/动量 |
| **RSI** | 相对强弱指标 | 超买超卖 |
| **布林带** | 股价波动区间 | 突破信号 |
| **换手率** | 成交量/流通股本 | 活跃程度 |

#### 2. 基本面因子

| 因子名 | 计算方法 | 含义 |
|-------|---------|------|
| **市盈率 (PE)** | 市值/净利润 | 估值高低 |
| **市净率 (PB)** | 市值/净资产 | 估值高低 |
| **ROE** | 净利润/净资产 | 盈利能力 |
| **净利润增速** | (今年-去年)/去年 | 成长性 |
| **营收增速** | (今年-去年)/去年 | 成长性 |
| **资产负债率** | 负债/资产 | 财务风险 |

#### 3. 资金流向因子

| 因子名 | 计算方法 | 含义 |
|-------|---------|------|
| **主力净流入** | 大单买入-大单卖出 | 资金方向 |
| **北向资金** | 港资买入金额 | 外资动向 |
| **龙虎榜机构净买入** | 机构买入-卖出 | 机构动向 |

#### 4. 情绪因子

| 因子名 | 计算方法 | 含义 |
|-------|---------|------|
| **涨停次数** | N日内涨停天数 | 热度 |
| **封板率** | 涨停封住次数/涨停次数 | 多头强度 |
| **换手率** | 成交量/流通股本 | 交易活跃度 |
| **量价齐升** | 涨且放量 | 资金推动 |

#### 5. 连扳专用因子（针对你的模式）

| 因子名 | 计算方法 | 含义 |
|-------|---------|------|
| **连板天数** | 连续涨停天数 | 强度 |
| **昨天涨停** | 涨跌幅>=9.9% | 动量起点 |
| **炸板次数** | 打开涨停板次数 | 抛压 |
| **首板时间** | 首次涨停的时间 | 强度 |

## 二、Alpha与Beta

### 2.1 什么是Alpha？

> **Alpha = 超额收益 = 跑赢大盘的部分**

```
你的收益 = 大盘涨跌幅 + Alpha
```

- Alpha > 0：跑赢大盘
- Alpha < 0：跑输大盘

**例子**：
- 大盘涨了10%，你赚了20%
- Alpha = 20% - 10% = **10%**

### 2.2 什么是Beta？

> **Beta = 市场风险系数**

| Beta值 | 含义 |
|-------|------|
| 1.0 | 与大盘同步 |
| > 1.0 | 波动比大盘大（涨更多，跌更多） |
| < 1.0 | 波动比大盘小 |
| < 0 | 与大盘负相关 |

**例子**：
- Beta = 1.5
- 大盘涨10% → 你涨15%
- 大盘跌10% → 你跌15%

### 2.3 对你的意义

- 追求 **高Alpha**：持续跑赢大盘
- 控制 **Beta**：不要波动太大（否则拿不住）

## 三、IC与IR

### 3.1 IC（信息系数）

> **IC = 预测值与实际收益的相关性**

```
IC = corr(因子值, 下期收益)
```

- IC > 0：因子正向有效（因子大 → 收益高）
- IC < 0：因子反向有效（因子大 → 收益低）
- IC ≈ 0：因子无效

**判断标准**：

| IC | 评价 |
|----|------|
| > 0.05 | 很好 |
| 0.02-0.05 | 一般 |
| < 0.02 | 较差 |

### 3.2 IR（信息比率）

> **IR = IC的稳定性 / IC的波动**

```
IR = mean(IC) / std(IC)
```

- IR越高：因子越稳定有效

**判断标准**：

| IR | 评价 |
|----|------|
| > 0.5 | 优秀 |
| 0.3-0.5 | 良好 |
| < 0.3 | 一般 |

## 四、 Barra风险模型

> 量化机构用的风险控制模型，把风险拆解为：

| 风险类型 | 说明 |
|---------|------|
| **市值因子** | 大盘股/小盘股风险 |
| **行业因子** | 各行业风险 |
| **动量因子** | 追涨杀跌风险 |
| **波动率因子** | 高波动风险 |
| **价值因子** | 低估值风险 |

**目的**：剥离风险，只赚Alpha的钱

## 五、策略分类术语

### 5.1 按频率分

| 类型 | 周期 | 特点 |
|-----|------|------|
| **高频交易 (HFT)** | 毫秒/秒 | 拼速度、拼硬件 |
| **日内交易 (DT)** | 当天买卖 | T+0、持仓短 |
| **短线** | 1-5天 | 追热点 |
| **中线** | 1-3个月 | 趋势跟踪 |
| **长线** | 1年以上 | 价值投资 |

### 5.2 按方法分

| 类型 | 特点 | 适合谁 |
|-----|------|-------|
| **趋势跟踪** | 追涨杀跌、顺势而为 | 你（连扳） |
| **均值回归** | 低买高卖、回归价值 | 震荡市 |
| **统计套利** | 找价格背离的配对 | 专业机构 |
| **事件驱动** | 炒消息、炒业绩 | 短线 |

## 六、绩效指标

| 指标 | 英文 | 含义 | 好的标准 |
|-----|------|------|---------|
| **收益率** | Return | 总收益 | 年化>20% |
| **胜率** | Win Rate | 盈利次数占比 | >40% |
| **盈亏比** | Profit/Loss | 平均盈利/平均亏损 | >1.5 |
| **最大回撤** | Max Drawdown | 最大亏损幅度 | <20% |
| **夏普比率** | Sharpe Ratio | 风险调整收益 | >1 |
| **卡玛比率** | Calmar Ratio | 收益/最大回撤 | >1 |
| **索提诺比率** | Sortino Ratio | 收益/下行波动 | >1 |

## 七、实盘术语

| 术语 | 含义 |
|-----|------|
| **Tick** | 行情数据的最小单位 |
| **滑点** | 实际成交价与信号的差距 |
| **流动性** | 买卖盘的深度 |
| **冲击成本** | 大单买卖对价格的影响 |
| **冰山委托** | 隐藏实际数量的委托 |
| **撤单率** | 撤单比例（太高说明策略有问题） |
| **成交率** | 成交笔数/发单笔数 |

## 八、你的连扳策略 = 什么类型的策略？

根据你之前说的模式：

| 维度 | 你的策略 |
|-----|---------|
| **频率** | 短线/超短线（1-3天） |
| **方法** | 趋势跟踪（追涨停） |
| **核心因子** | 涨停、连板、换手率、成交量 |
| **Alpha来源** | 涨停惯性、情绪溢价 |
| **风险** | 高Beta、高回撤 |

---

## 本课重点

1. **因子 = 选股标准**（价格/基本面/资金/情绪）
2. **Alpha = 超额收益**（跑赢大盘的部分）
3. **IC = 因子有效性**（预测能力）
4. **回撤控制**是活下来的关键
5. **你的连扳策略**：趋势跟踪 + 动量因子 + 情绪因子
