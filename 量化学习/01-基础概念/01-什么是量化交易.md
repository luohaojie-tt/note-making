## 第一课：什么是量化交易？

### 1.1 量化交易的本质

**量化交易 = 用数学模型 + 计算机程序 替代人为决策**

| 主观交易（你现在的模式） | 量化交易 |
|------------------------|---------|
| 人脑判断买卖点 | 数学模型判断买卖点 |
| 情绪影响决策 | 完全执行策略，无情绪 |
| 盘中临时决策 | 提前制定策略，自动执行 |
| 复盘靠记忆 | 复盘靠数据回测 |

### 1.2 量化交易的核心优势（对你连扳选手的价值）

1. **回测验证** - 可以用历史数据验证策略是否有效，不只是靠实盘"交学费"
2. **纪律性强** - 不会因为"上头"而乱买，严格执行模式
3. **覆盖广** - 可以同时监控全市场4000+股票，找到所有符合模式的标的
4. **响应快** - 量化程序可以毫秒级响应行情变化（这正是你被收割的原因）

### 1.3 量化交易的分类

作为个人投资者，你只需要关注两种：

| 类型 | 特点 | 适合你吗 |
|-----|------|---------|
| **趋势跟踪** | 追涨杀跌，顺势而为 | ✅ 你做连扳本来就是趋势 |
| **均值回归** | 低买高卖，回归价值 | ❌ 不适合短线 |

**你做连扳接力的本质就是趋势跟踪**，所以转型量化很自然。

### 1.4 最小化量化系统需要什么？

```
数据源 → 选股模型 → 买入信号 → 卖出信号 → 风控 → 回测 → 实盘
```

作为散户，你不需要全部自己写，可以：
- **数据源**：花点钱买（如Tushare Pro）
- **回测框架**：用Backtrader、Backtesting等开源库
- **实盘通道**：券商API（同花顺/东财量化接口）

- 量化 = 数学模型 + 程序执行
- 核心价值：用回测验证策略，减少无效实盘交易
- 你做连扳的本质是趋势跟踪，转型量化很自然
