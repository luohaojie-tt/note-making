# Claude Code 桌面自动化 Skills 推荐

用于操作电脑上的应用程序（如同花顺等Windows桌面应用）的 Skills。

---

## 推荐 Skills

### 1. winapp-cli ⭐ 7K installs

专门用于 Windows 桌面应用的自动化操作。

- **安装命令**: `npx skills add github/awesome-copilot@winapp-cli -g -y`
- **文档**: https://skills.sh/github/awesome-copilot/winapp-cli
- **用途**: 操作 Windows 应用程序，包括点击、输入、截图等

---

### 2. desktop control 1.2K installs

通用的桌面控制技能。

- **安装命令**: `npx skills add patrickporto/desktop-agent@desktop-control -g -y`
- **文档**: https://skills.sh/patrickporto/desktop-agent/desktop-control
- **用途**: 桌面应用的通用控制

---

### 3. Windows UI Automation 386 installs

专注于 Windows UI 元素的自动化。

- **安装命令**: `npx skills add martinholovsky/claude-skills-generator@windows-ui-automation -g -y`
- **文档**: https://skills.sh/martinholovsky/claude-skills-generator/windows-ui-automation
- **用途**: Windows 界面元素的识别与操作

---

### 4. Desktop Computer Automation 439 installs

更通用的桌面计算机自动化。

- **安装命令**: `npx skills add web-infra-dev/midscene-skills@desktop-computer-automation -g -y`
- **文档**: https://skills.sh/web-infra-dev/midscene-skills/desktop-computer-automation

---

### 5. browser-automation 758 installs

浏览器自动化（适用于 Web 版应用）。

- **安装命令**: `npx skills add sophieguanongit/openclaw-browser-automation@browser-automation -g -y`
- **文档**: https://skills.sh/sophieguanongit/openclaw-browser-automation/browser-automation

---

## 使用建议

**推荐**: 对于操作同花顺这类 Windows 桌面应用，**winapp-cli** 是最热门且专门为此设计的。

> [!tip]
> 可以通过 `npx skills find [关键词]` 搜索更多相关 Skills。
>
> 浏览更多 Skills: https://skills.sh/
